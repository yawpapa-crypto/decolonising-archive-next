# ARED User Testing Plan (Metadata Transparency + Discoverability)

## Participant profiles

1. Data specialist  
2. UX designer  
3. Archive researcher  
4. Student  
5. Community historian  
6. First-time visitor  
7. Regular signed-in user  
8. Screen-reader user

## Core tasks

1. Identify which metadata fields came from the source institution.
2. Identify which metadata fields were added/normalised by ARED.
3. Explain the difference between Knowledge area, Concept and Tag.
4. Create a personal collection.
5. Save a featured record.
6. Find Community knowledge and responses.
7. Suggest a correction with supporting source.
8. Compare source metadata with ARED enrichment.

## Metrics captured

- Success rate by task and participant profile
- Time on task
- Confusion points / hesitation moments
- Abandoned tasks
- Terminology misunderstandings
- Discoverability failures
- Accessibility blockers (keyboard, SR, zoom, touch)

## Data collection template

For each task capture:

- Task ID
- Participant profile
- Completed (Y/N)
- Time (seconds)
- Errors encountered
- Confidence rating (1–5)
- Notes

## Exit questions

- Which provenance labels were easiest/hardest to interpret?
- What was unclear in Tags vs Concepts vs Knowledge areas?
- Did the collection workflow feel discoverable?
- Which labels felt contested or potentially misleading?
- What would improve trust in record metadata?
